## ✨ Sobre

O **Bypass X67** é um painel bash interativo desenvolvido para **Termux** que permite identificar e remover packages suspeitos do seu Android via **ADB (Android Debug Bridge)**.

Ideal para quem precisa limpar o sistema antes de gerar bugreports oficiais, removendo rastros de:
- Mod menus (GringoXP, etc)
- Proxies e VPNs modificadas
- Apps de terceiros suspeitos
